SimplMaker 0.1.1 (beta)

  • Copy and paste bodies (Edit ▸ Copy, Paste), within a part or between parts; a pasted body opens in Move so you can slide it off the original.
  • New first-run tutorial: build a desk organizer step by step.
  • Drag a parameter's name left or right to change its value; right-click to rename or delete.
  • Planar face normals fixed so chamfer faces point outward; clearer Chamfer limits at rounded corners.
  • Sketch mode: left-drag on empty space orbits, as in Design mode.
  • New Measure tool, Project tool, example parts, accent colour and many smaller refinements.
  • Parametric sketches, extrude, revolve, sweep, loft, fillet, chamfer, threads and more.
  • 14-day free trial, then a license key.
  • Automatic updates.
  • License activation: if a key from another major version is turned away, its activation slot is now freed reliably (retried if the license server is busy).
