SimplMaker 1.2.0

SimplMaker is now free and open source. The price tag has been taken down, and the trial clock with it.

  • Free: no trial, no license key, no "Editing is off" banner. This update unlocks every copy, including ones whose 14 days ran out. Nothing to enter, nothing to deactivate; the License window and the Buy menu item are gone.
  • Open source: SimplMaker is released under the GNU General Public License, version 3 or later, and the code is at github.com/atlemo/SimplMaker. Read it, build it, fix it, send a pull request. If you bought a license: thank you, and you do not need to do anything.
  • The AI assistant connection no longer asks about a license either.
  • Updates and usage statistics: only the builds published on simplmaker.com check for updates and send anonymous usage statistics (still one switch to turn off, in Settings). A copy built from the source does neither.
  • About SimplMaker now says what SimplMaker is, and where its source lives.
