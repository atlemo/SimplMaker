SimplMaker 0.1.3 (beta)

  • Sketch angle dimensions are easier to place, and big angle changes now solve in steps, so the sketch keeps up instead of throwing a tantrum.
  • New Canvas tool, and an experimental Gear tool for spur gears in Sketch mode. Offset gets a new icon too.
  • The toolbar tucks its tools into group menus, then one single Tools menu, as the window gets narrower.
  • The selected tab's title is now readable on the Sketch mode tint.
  • Optional anonymous usage statistics (app start and tutorial completed, nothing else). Turn them off in Settings ▸ General if you would rather not be counted.
  • The About panel now carries the Open CASCADE license notice.
