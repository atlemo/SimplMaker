SimplMaker 0.1.3 (beta)

  • Sketch angle dimensions: easier to place, and large angle changes now solve in steps so the sketch follows.
  • New Canvas tool and an experimental Gear tool for spur gears in Sketch mode; new icon for Offset.
  • The toolbar collapses its tools into group menus, then a single Tools menu, as the window narrows.
  • The selected tab's title is readable on the Sketch mode tint.
  • Optional anonymous usage statistics (app start and tutorial completed only); turn them off in Settings ▸ General.
  • About panel now carries the Open CASCADE licence notice.
