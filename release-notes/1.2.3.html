SimplMaker 1.2.3

You can now repeat a debossed logo, a cut or a hole around a part, and Project got a good deal tougher.

  • Pattern repeats features, not just bodies: switch the Pattern tool (T) to Features, click a projection, cut, join or hole (on the model or in the timeline), then pick the axis. Each copy goes in the way the original did. Right-click a feature and choose Repeat in a Circle… or Repeat in a Row… for the short way.
  • Go round whatever you click: a round face, a circular edge or a straight edge can be the axis, so a cylinder that sits off the origin works too. The pattern is made the moment the last thing is picked, no Return needed. For AI assistants, create_pattern takes features and the same axes.
  • Project is tougher: touching profiles are merged first, so a text with 283 letters no longer fails or takes forever. A flat face you picked decides which way the profiles go, and a projection that finds nothing is tried the other way before it complains. Right-click a sketch in the browser for Project Sketch.
  • Sketch selection: drag across empty space to select (left to right takes what is wholly inside, right to left takes what it touches), ⌘A selects everything, and a drag no longer orbits the view while you sketch.
  • Holes on curved faces: place one on a cylinder or a sphere and it drills along the surface at the spot you clicked.
  • Threads follow their hole: change a hole's diameter parameter and its thread is fitted again instead of failing.
  • The panel toggles in the toolbar sit at the same height as the panels, the Render view hides the status bar and puts its floor below zero, and there is a new app icon and a GitHub Sponsors link.
