SimplMaker 1.1.7

SimplMaker files look like SimplMaker files in Finder, File > Rename works, and ellipses can be offset.

  • New document icon for .simplmaker files.
  • Finder and Quick Look can show a picture of the part instead of the file's text. The picture is saved with the part, so files saved with this version get one the next time you save them.
  • File > Rename: it does something now. It asks for the new name in a sheet and renames the file. It is greyed out until the document has been saved.
  • Browser: the name field you get when renaming an item no longer closes itself right after the context menu does.
  • Offset: sketched ellipses can be offset. The result is a smooth closed curve, so it has no dimension to edit, the same as an offset Bézier.
