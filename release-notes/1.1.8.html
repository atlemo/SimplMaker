SimplMaker 1.1.8

A command palette, 3MF and DXF files, tidier parameters, and error messages that name the culprits.

  • Command palette: press ⌘K, type what you want, press Return. It finds tools, view and file commands, and an Edit entry for every feature in the timeline.
  • Browser: drag bodies, sketches, planes and canvases onto another row of the same kind to put them in the order you like. The order is saved with the file and changes nothing in the model.
  • Parameters: keep them in folders, and put folders inside folders. Use the folder button in the Parameters header, the right-click menu, or drag. Renaming a parameter keeps it in its folder. Folders are only for tidiness: no value changes and nothing rebuilds.
  • 3MF export: one object per body, in millimetres, with each body's colour.
  • DXF: import lines, arcs, circles, polylines, ellipses and splines, and export sketches as DXF.
  • Sketch constraints: when constraints or dimensions fight each other, or say the same thing twice, the error names them, they turn red in the sketch, the Inspector marks them, and the status line says which.
  • Split: Split into Parts separates loose pieces, the pieces a split makes can be renamed in the browser, and Combine now starts on Join.
  • Sketch mirror: a button on the mirrored image opens the mirror for editing.
  • Hidden edges: the line colour is picked against the body's own colour, so it stays readable.
  • Assistant: SimplMaker opens by itself on the assistant's first request, and answers start-up questions from its last list of tools.
