## What you need

- A Mac with **Apple silicon** (M1 or later)
- **macOS 15** or later
- A trackpad or a mouse. A trackpad is nicer for orbiting.

SimplMaker is free and works offline. It needs the internet only to look for updates and to send anonymous usage statistics (which you can turn off in **Settings → General**).

## Install

1. [Download SimplMaker](/download/). You get a disk image called `SimplMaker.dmg`.
2. Open it and drag **SimplMaker** onto the **Applications** folder.
3. Open SimplMaker from Applications. The official build is signed and notarised by Apple, so it opens without a warning.

The first thing you see is the [welcome window](doc:start/examples-and-tutorial).

There is no licence key, no account and no sign-in. SimplMaker is open source; see [Licence and source](doc:reference/license-and-source) if you would rather build it yourself.

## Updates

SimplMaker looks for updates by itself. To check now, choose **SimplMaker → Check for Updates…**. To turn the automatic check off, open **Settings → General**, where you can also turn off the anonymous usage statistics that SimplMaker sends to TelemetryDeck. What changed in each version is in the [changelog](/changelog/).
