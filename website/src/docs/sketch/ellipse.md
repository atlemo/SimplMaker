---
title: Ellipse
description: Draw an ellipse from its centre and two axes, with the axes kept square, and change its size with dimensions.
---

An **ellipse** is a stretched circle. Press [[J]] for the **Ellipse** tool. You set it with three clicks: the centre, the end of one axis, and how far the other axis reaches.

## Draw one

1. Press [[J]].
2. Click the **centre**.
3. Click the **end of one axis**. The ellipse runs through this point, and that axis is set from the centre to it.
4. Move the pointer across the first axis to set the other axis. The ellipse changes as you move, so you can see it. Click to place it.

The two axes stay at right angles to each other. They are drawn as construction lines, dashed, so they guide the shape without making it a solid profile.

## Size

- Both axes are dimensions. Each one is measured from the **centre** to the end of the axis. A first axis 60 mm long across, for example, is dimensioned as 30 mm.
- Change a size by editing its dimension, as described in [Dimensions](doc:sketch/dimensions).
- You can't type sizes while drawing an ellipse. Click the three points, then set the size with the dimensions.

:::note
The other axis must reach out from the first one. If the third click lands on the first axis, the ellipse has no width and SimplMaker says so.
:::

An ellipse is a closed shape, so you can extrude it like any other profile. To use an ellipse made in another program, import it as SVG: see [Import SVG](doc:sketch/import-svg).
