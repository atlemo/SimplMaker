title: Revolve
description: Spin a profile around an axis to make a round shape: a vase, a knob, a wheel, a ring.
---

**Revolve** turns a profile around an axis. Key: [[R]] in design mode.

## Use it

1. Sketch half of the shape, and draw a line to use as the **axis**, along one side of the profile.
2. Press [[R]] for **Revolve** and click the **profile**.
3. Click the **line** you drew to use as the axis. Or press [[Return]] to use the sketch's vertical axis.

The shape appears. Drag the arrow to set the angle, or type it.

![Editing a revolve.](shot:revolve-edit)

:::tip
Make the axis line a **construction line** (select it and press **Construction**). If a sketch has one, Revolve uses the first construction line as its axis when you don't pick one.
:::

## Inspector

![The revolve inspector.](shot:inspector-revolve)

| Field | What it does |
|---|---|
| **Angle** | How far to turn. `360 deg` goes all the way round. |
| **Axis** | Sketch vertical, Sketch horizontal, X axis, Y axis, Z axis, or a line you picked. **Use the selected line as the axis** switches to a line. |
| **Operation** | New Body, Join, Cut or Intersect |
| **Profiles** | How many are used. **Reselect…** picks them again. |

## Tips

- The profile must not cross the axis.
- For a hollow shape, sketch the profile as a thin outline rather than a solid half.
