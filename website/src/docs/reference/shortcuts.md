## While sketching

While you sketch, the letters pick sketch tools instead.

| Key | Tool |
|---|---|
| [[S]] | Select |
| [[L]] | Line |
| [[R]] | Rectangle. Press again for the centre rectangle. |
| [[C]] | Circle. Press again for the 2-point circle. |
| [[G]] | Polygon. Press again for a triangle. |
| [[A]] | Arc. Press again for the 3-point arc. |
| [[B]] | Spline |
| [[K]] | Gear |
| [[P]] | Point |
| [[X]] | Text |
| [[F]] | Round Corner |
| [[T]] | Trim |
| [[E]] | Extend |
| [[I]] | Dimension |
| [[D]] | Distance |

Other keys while sketching:

| Key | Does |
|---|---|
| [[Return]] | Finish the sketch, or place the shape you typed values for |
| [[Esc]] | End a chain, cancel the tool, or clear the selection |
| [[⌫]] | Delete the selection |
| [[⇧]]-click | Add to the selection |
| [[⌥]] while clicking | Switch snapping off |
| [[Tab]] | Next typed field |

## Change a shortcut

Open **Settings → Shortcuts** to give any tool or command a different key. Shortcuts with ⌘, ⌃ or ⌥ always run. A bare letter is passed on to a text field when you are typing in one.
