---
title: Glossary
description: The CAD words used in SimplMaker, in plain language.
---

**Assembly.** A model made of several bodies that fit together. SimplMaker handles several bodies in one part, but does not have joints.

**Body.** One solid shape. A part can have many bodies. They are listed in the browser.

**Canvas.** A picture placed on a plane, to trace over.

**Chamfer.** A bevelled edge.

**Constraint.** A rule between sketch shapes: parallel, equal, tangent and so on.

**Construction geometry.** Dashed helper lines in a sketch that don't make solids.

**Construction plane.** A reference plane you place yourself, to sketch on or mirror across.

**Degrees of freedom (DOF).** How many ways a sketch can still move or change. Zero means fully constrained.

**Dimension.** A fixed size or distance in a sketch.

**Edge.** The line where two faces meet.

**Expression.** A value you write as a formula, such as `width / 2 + 3 mm`.

**Extrude.** Push a flat shape into a solid.

**Face.** A surface of a body.

**Feature.** One step in building a part: a sketch, an extrusion, a fillet. They are listed in the timeline.

**Fillet.** A rounded edge.

**Loop.** A closed chain of edges around a face.

**Marker.** The orange mark on the timeline that shows how far the model is built. Drag it back to roll the model back.

**Normal.** The direction a face points: straight out of its surface.

**Orthographic.** A view without perspective, where parallel lines stay parallel.

**Parameter.** A named value you can use anywhere, such as `width`.

**Parametric.** Built from values and rules, so changing one value rebuilds the model.

**Profile.** A closed shape in a sketch that a tool can use, such as the outline you extrude.

**Rebuild.** SimplMaker working out the geometry again from the features. It happens automatically.

**Roll back.** Moving the marker earlier, so you see and edit the model as it was at that point.

**Sketch.** A flat drawing on a plane or face.

**Solid.** A closed 3D shape with an inside.

**STEP.** A neutral CAD file format that keeps exact shapes.

**STL.** A file format made of triangles, used by slicers.

**Suppress.** Switch a feature off without deleting it.

**Timeline.** The list of features in the order they were made.

**Tolerance.** A small allowance added to a size so printed parts fit together.
