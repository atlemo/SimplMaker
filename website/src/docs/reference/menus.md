## SimplMaker

| Item | Does |
|---|---|
| **About SimplMaker** | Version, credits and open-source licenses |
| **Check for Updates…** | Looks for a new version |
| **Settings…** ([[⌘,]]) | The settings window, including the AI connection. See [Settings](doc:reference/settings) and [Work with an AI assistant](doc:ai/assistant). |

## File

| Item | Does |
|---|---|
| **New** ([[⌘N]]), **Open…**, **Open Recent** | Standard document commands |
| **Open Example Parts** | Three parts to learn from |
| **Close**, **Close All**, **Save**, **Save As…** | Standard document commands |
| **Duplicate**, **Rename…**, **Move To…** | Standard document commands |
| **Revert To** | Go back to the last saved version, or browse all versions |
| **Share** | The system's share sheet |
| **Import ▸ STEP…** ([[⇧⌘I]]) | Add a STEP file as a body |
| **Import ▸ STL…** | Add a watertight STL mesh as a body |
| **Import ▸ SVG as Sketch…** | Turn an SVG into a sketch |
| **Export…** | Write the bodies to STL or STEP files, as one part or as individual parts |
| **Export Image…** | Save what the 3D view shows as a PNG or JPEG picture, with a preview, and for PNG with a transparent background |

## Edit

Standard **Undo** ([[⌘Z]]), **Redo** ([[⇧⌘Z]]), **Cut**, **Copy**, **Paste**, **Delete** and **Select All**.

**Copy** and **Paste** also work on bodies: copy a body and paste it into the same part, another part or another window. It comes in as an imported body. See [Files](doc:concepts/files).

## View

| Item | Does |
|---|---|
| **Fit All** ([[⌘0]]) | Zooms to show the whole model |
| **Standard Views** | Top, Front, Right and Home |
| **Orthographic Projection** | Switches between perspective and orthographic |
| **Visual Style** | Shaded, wireframe and hidden-edge styles |
| **FDM 3D Print Preview** | Draw the bodies like a printed part, with layer lines. Shaded styles only. See [3D Print Preview](doc:print/print-preview). |
| **Render** | Show the part on a solid floor with a light you set, shadows and a reflection. See [Render view](doc:modify/render). |
| **Render Options** | Show or hide the Render view's panel while the view is on |
| **Section Analysis** | Turn the cut through the bodies on or off (see [Section Analysis](doc:modify/section-analysis)) |
| **Exploded View** | Slide the bodies apart with a slider, to show how the part is built up. See [Exploded view](doc:modify/exploded-view). |
| **Show Grid**, **Show Axes** | Toggle the reference lines |
| **Show Constraints** | Show or hide sketch constraint symbols |
| **Snap to Grid** | Toggle grid snapping in sketches |
| **Hide/Show Browser**, **Timeline**, **Inspector** | Toggle the panels |
| **Show/Hide Appearance** | Opens the colour and material panel |
| **Show Tab Bar**, **Show All Tabs**, **Enter Full Screen** | Standard window commands |

## Sketch

| Item | Does |
|---|---|
| **New Sketch…** | Starts a sketch: pick a plane or face |
| **New Sketch On** | **XY Plane**, **XZ Plane**, **YZ Plane** or **Selected Face** |

While you are editing a sketch, the menu also lists the sketch tools, **Offset Selection…**, **Move Selection**, **Scale Selection…**, **Pattern Selection**, **Mirror Selection**, **Slice View** (see [Starting a sketch](doc:sketch/start)) and **Finish Sketch**.

## Create

**Extrude**, **Revolve**, **Sweep**, **Loft**, **Rib**, **Pipe**; **Box**, **Cylinder**, **Sphere**, **Torus**, **Coil**; **Construction Plane**, **Canvas (Reference Image)…**; and **Rebuild** ([[⌘R]]).

## Modify

**Fillet**, **Chamfer**, **Hole**, **Thread**, **Shell**, **Draft**, **Project**, **Move**, **Scale**, **Lay on Floor**, **Combine**, **Split Body**, **Mirror**, **Pattern**.

## Inspect

**Measure**, **Section Analysis**.

## Window

Standard window commands, including **Move Tab to New Window** and **Merge All Windows** (parts open as tabs), plus **Welcome to SimplMaker** ([[⇧⌘1]]).

## Help

**Tutorial: Make a Desk Organizer**, or **Resume Tutorial** if you closed it.
