Features

Everything
a part needs.

A focused CAD tool: sketch, shape, finish, export. Every value is an expression, so change one number and the model rebuilds itself while you watch.

01

Parameters
drive it all.

Define width, wall or tolerance once and use them anywhere. Values take units and maths: depth / 3, 1 in, hole_d + 0.2 mm.

  • Named parameters, shared across the part
  • Units: mm, cm, in and more
  • Autocomplete in every field
{{clip:parameters|1728/1080|Clip · edit the width parameter, the sketch, extrusion and fillet all follow}}

02

Sketch with
constraints.

Lines, arcs, circles, rectangles, splines and points, held in place by dimensions and constraints. Drag a corner and the sketch moves as far as the constraints allow.

  • Coincident, parallel, perpendicular, tangent, equal, concentric and more
  • Trim, extend, offset, corner fillet
  • Live degrees-of-freedom count
{{clip:sketch|1728/1080|Clip · draw a bracket profile, add dimensions, drag a corner to see the solver work}}

03

Pull it
into 3D.

Extrude, revolve, sweep, loft, rib and pipe, all with a drag handle and a typed value. Start from a box, cylinder, sphere, torus or coil when that is quicker.

  • One direction, two directions or mirrored
  • New body, join, cut or intersect
  • Move, rotate and scale bodies and sketches
{{clip:extrude|1728/1080|Clip · select a profile, drag the extrude arrow, switch between join and cut}}

04

Finish
the details.

Fillet and chamfer edges, shell a body hollow, drill holes and cut threads. Features refer to faces and edges by stable names, so they stay put when you change the dimensions upstream.

  • Fillet, chamfer (equal, distance and angle, two distances)
  • Shell, hole, thread
  • Body colours that save with the part
{{clip:finish|1728/1080|Clip · fillet the edges, shell it hollow, add a threaded hole}}

05

A timeline
you can edit.

Every step is a feature in the timeline. Click one to edit it, suppress it, or roll back and change an earlier sketch. If a feature fails, the ones after it still rebuild and the problem is marked.

  • Edit any sketch or feature later
  • Suppress and delete
  • Errors explain themselves on hover
{{clip:timeline|1728/1080|Clip · roll back the timeline, edit an early sketch, everything after rebuilds}}

06

In from STEP.
Out to STL.

Import a STEP file and keep modelling on it: fillet it, cut it, move it. Export your bodies as STL or 3MF for the slicer, or as STEP for any other CAD tool. Sketches go in and out as DXF.

  • Import STEP, STL and DXF; export STEP, STL, 3MF and DXF
  • Imported files are stored inside the part
  • Your files are yours: no cloud, no lock-in
{{clip:export|1728/1080|Clip · import a STEP file and keep modelling on it}}

07

Properly
a Mac app.

Native, fast and well-behaved. Metal viewport, one window per part, autosave and versions, light and dark mode, trackpad gestures. It works offline, needs no account and costs nothing.

  • Built for Apple Silicon
  • Autosave, versions and Open Recent
  • No browser tab, no upload, no staring at a spinner
{{clip:mac|1728/1080|Clip · orbit with the trackpad, switch to dark mode, open a recent part}}

What it
doesn't do.

  • No assemblies with joints
  • No CAM or simulation
  • Mac only: macOS 15, Apple Silicon
