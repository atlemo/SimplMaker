Third-party components

SimplMaker includes other people's work, and each part keeps its own licence. The full texts are in the app, under SimplMaker → About SimplMaker.

  • Open CASCADE Technology, the geometry kernel: GNU LGPL 2.1 with the Open CASCADE exception. It is a separate, replaceable library in the app; the Open CASCADE page in the docs says where its source is and how to swap in your own build.
  • DelaBella (shipped with Open CASCADE): MIT License.
  • Sparkle, which handles updates: MIT License, with bundled code under BSD and zlib-style licences.
  • Lucide icons, with some Feather icons: ISC License; Feather portions MIT License.
  • TelemetryDeck SDK, for the anonymous usage statistics described in the privacy policy: MIT License.

Name and icon

The GPL covers the code. It does not cover the name SimplMaker or the app icon, which are not licensed for use in other products. If you publish a modified version, a fork or a build of your own, give it a different name and a different icon, and do not present it as the official SimplMaker. Saying that your project is "based on SimplMaker" or "a fork of SimplMaker" is fine.

Builds that carry the SimplMaker name and are downloaded from this website are the official ones. They are signed and notarised by Apple.
